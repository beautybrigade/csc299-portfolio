# CSC 299 Final Project Portfolio

| Project | Kind | Repository | What it does |
|---------|------|------------|--------------|
| polish-tracker | web | https://github.com/beautybrigade/polish-tracker | Tracks a nail polish collection by brand, color, and finish, and stops you from adding a polish you already own. |
| nail-salon-tycoon | game | https://github.com/beautybrigade/nail-salon-tycoon | A browser and terminal game where you work a day as a new nail technician, doing each service's steps in the right order to earn stars and money. |
| supply-checker | CLI | https://github.com/beautybrigade/supply-checker | Reads a CSV of salon supplies, shows stock in packs or units, and flags anything below its minimum. |
